# GitHub 公開手順

## 1. 初期確認

公開前に以下を確認します。

- `skills/<skill-name>/SKILL.md` が存在する。
- `SKILL.md` の `name` と directory name が分かりやすい。
- secrets, local paths, private notes が含まれていない。
- 公開 license を決めている。
- 外部Skillには採用元と採用コミットを記録し、配布元のlicense / noticeを保持する。
- 廃止したSkillは`archive/skills/`へ保管し、`SKILL.md`を`旧手順.md`へ改名して、インストール対象から除外する。

## 2. Git Repository の作成

```powershell
git init
git add .
git commit -m "Initial skills repository"
```

## 3. GitHub Repository の作成

GitHub で空の repository を作成してから、表示される remote URL を設定します。

```powershell
git branch -M main
git remote add origin https://github.com/<owner>/<repo>.git
git push -u origin main
```

## 4. 公開後の運用

- skill ごとに directory を分ける。
- README に追加した skill の概要を追記する。
- breaking changes がある場合は commit message または release notes に残す。
