# 実行手順

## 前提

Python 3.10以降、FFmpegとffprobeが必要。Pythonの追加パッケージは不要。FFmpegには`libx264`、AAC、`atempo`などが必要で、字幕合成時は`subtitles`フィルター（libass対応）が必要。コマンドの先頭にある`python`は環境の実行ファイルに置き換えてよい。

以下はSkillディレクトリから実行する例。PATHにない実行ファイルは、サブコマンドの前に`--ffmpeg "実行ファイルのパス" --ffprobe "実行ファイルのパス"`を指定する。入力はローカルファイルを対象とし、ネットワークURLを受け付けない。

```powershell
python scripts/video_workflow.py inspect "素材/プレイ動画.mp4"
python scripts/video_workflow.py frames "素材/プレイ動画.mp4" --output "制作/確認画像" --count 12
python scripts/video_workflow.py frames "素材/プレイ動画.mp4" --output "制作/候補前後" --start 20 --end 25 --count 10
python scripts/video_workflow.py render "制作/edit.json" --output "制作/preview.mp4" --preview
python scripts/video_workflow.py render "制作/edit.json" --output "制作/final.mp4"
```

`frames`は指定区間の各分割の中央からJPEGを抽出し、時刻とファイル名を`index.json`へ保存する。画像を見せ場の判断や文字確認に使う。ファイルが生成されたことだけでは映像を確認したことにならない。

## 編集データ

次のJSONは、音声付き動画の区間をカットしてつなぎ、2場面目を半速・中央拡大にし、最後に画像を表示する例。素材のパスはJSONのあるディレクトリを基準に解決する。`intent`と各クリップの`label`は構成意図を残すメモで、動画に表示されない。

```json
{
  "intent": "決定的な場面を強調する短いPV。原音は残す",
  "width": 1920,
  "height": 1080,
  "fps": 30,
  "clips": [
    {"file": "../素材/プレイ動画.mp4", "start": 2, "end": 6, "fade_in": 0.2, "label": "導入"},
    {"file": "../素材/プレイ動画.mp4", "start": 10, "end": 12, "speed": 0.5, "zoom": 1.15, "label": "見せ場"},
    {"file": "../素材/タイトル.png", "type": "image", "duration": 2, "fade_out": 0.3}
  ],
  "music": {"file": "../素材/BGM.wav", "volume": 0.25, "start": 0},
  "subtitles": "captions.ass"
}
```

この例は4秒＋4秒＋2秒で約10秒。素材の区間が存在することを確認して値を変更する。BGMや字幕がなければ該当キーを省略する。全素材を出力の縦横比に余白付きで合わせ、クロップする場合は`zoom`で中央を拡大する。`--preview`は縦横比・尺・fps・音を維持し、長辺を最大960pxに下げる。

| 項目 | 意味・初期値 |
| --- | --- |
| `width`, `height`, `fps` | 正の偶数解像度と整数fps。初期値1920×1080、30fps |
| `clips` | 順番に結合するクリップ。映像間の重なりはなし |
| `file` | 存在する素材ファイル |
| `type` | `video`（初期値）か`image`。画像では明示する |
| `start`, `end` | 動画の元素材上の秒数。初期値は0から素材の末尾まで |
| `duration` | 静止画像を表示する秒数。画像では必須 |
| `speed` | 動画の定速倍率。初期値1、範囲0.25〜4。原音は同倍率で音程を保って変更 |
| `zoom` | 中央拡大倍率。初期値1、範囲1〜3。拡大後に余白付きで出力サイズへ合わせる |
| `volume`, `mute` | 原音の倍率（初期値1、範囲0〜4）と消音（初期値false）。音声なし素材は無音を補う |
| `fade_in`, `fade_out` | 各クリップの映像を黒から／黒へフェードする秒数。音には適用しない。初期値0 |
| `music.file`, `music.start`, `music.volume` | BGM、再生開始位置、音量倍率（初期値0秒・0.25）。短いBGMは繰り返し、動画尺へ切り、最後の最大1秒をフェードアウト |
| `subtitles` | UTF-8の`.srt`または`.ass`。時刻は完成動画の時間軸 |

字幕は別途作成する。装飾付きの日本語字幕ではASSのフォント名・サイズ・位置・改行を明示し、使用フォントが環境にあることを確認する。SRTの既定表示でも読めるか実際のフレームで確認する。

既存の出力ファイルや確認画像ディレクトリは上書きしない。修正時は別の出力名を使う。入力元も変更しない。失敗時に一時的な中間動画は消えるが、元素材と編集JSONは残る。

## ヘルパーの境界

このヘルパーは基本編集の再利用を目的とする。スピードランプ（連続した速度変化）、クロスフェード、任意位置のズーム、効果音、ロゴ、色調整、文字の動き、ビート検出や見せ場の意味判定は実装していない。依頼に必要なら専用の処理を追加する。音楽の繰り返しも拍を自動でそろえる機能ではない。

検証は`python -m unittest discover -s scripts/tests -v`で実行する。実動画テストは環境変数`VIDEO_EDIT_FFMPEG`と`VIDEO_EDIT_FFPROBE`へ実行ファイルを指定すると有効になり、未指定時はスキップを表示する。
