# Example Skill

## When To Use

Use this skill as a starting point when creating a new custom skill.

## Workflow

1. Replace the `name` and `description` in the frontmatter.
2. Describe when the skill should be used.
3. Write the smallest repeatable workflow that helps Codex perform the task.
4. Add `scripts/`, `assets/`, or `references/` only when they materially improve the workflow.

## Output

Summarize what changed and mention any files that were created or updated.
