# create-agents-mdの廃止理由

- 廃止日: 2026-10-06
- 旧Skill名: `create-agents-md`
- 置き換え先: [create-agentsmd](../../../skills/create-agentsmd/SKILL.md)

## 置き換えた理由

旧版と採用先は、リポジトリの実態を調べ、既存の有用な指示を保持しながら`AGENTS.md`を作成・改善する役割が重複している。採用先には、コマンドや規則の根拠を追跡する、CIの定義と照合する、monorepoの階層別指示には差分だけを記載する、設定を読んだだけのコマンドを実行済みと報告しない、という手順が明記されている。

これらの手順を利用し、同じ目的のSkillを別々に維持する負担を減らすため、ユーザーの承認を得て置き換えた。旧版の基本方針が誤っていたことや、すべての依頼で採用先が優れることを廃止理由とはしない。採用判断は指示本文と関連資料の比較によるもので、同一条件での実行性能比較は未実施である。

## 保管したもの

- [旧手順.md](旧手順.md): 置き換え直前のリポジトリ版`SKILL.md`。ファイル名だけ変更し、内容を保存した。
- [agents/openai.yaml](agents/openai.yaml): リポジトリ版の表示設定。
- [installed/旧手順.md](installed/旧手順.md): 置き換え直前に利用していた日本語版。リポジトリ版と内容が異なるため、別に保存した。
- [installed/agents/openai.yaml](installed/agents/openai.yaml): 日本語版の表示設定。

ここは履歴の参照先であり、現役Skillとしてインストールしない。`SKILL.md`を置かず、再帰的なSkill探索でも旧版が重複して検出されないようにする。

## 復元が必要な場合

復元する版を選び、`旧手順.md`を`skills/create-agents-md/SKILL.md`として戻し、対応する`agents/openai.yaml`も戻す。利用環境へコピーするときは、採用先と旧版が同じ依頼に重複して選ばれないよう有効な版を一つにする。既存ファイルを上書きする前に利用環境の差分を確認し、Skills一覧と廃止理由も現在の状態に合わせて更新する。
